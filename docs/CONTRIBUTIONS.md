# Contributions

TripWeaver is a solo project. The course teacher gave permission for one person instead of a group of 2–3 (decision D45).

| Member | Role | Work |
|---|---|---|
| soham2121 (project owner) | Sole developer | All of it: requirements and scope, data pipeline (OSM ingestion, curated sources, Supabase/PostGIS), all five assessed algorithms and their tests and benchmarks, the planners (itinerary, road trip), backend API, frontend, collaboration features and documentation |

## Algorithms the owner presents in the viva

All five: Trie (Unit 4), Randomized Quickselect (Units 1 and 6, CO5), Greedy Weighted Set Cover (Unit 5), Binary Max Heap / Indexed Heap (Unit 2) and Metric TSP Double-Tree (Unit 5). For each, see `docs/ALGORITHM_DESIGN.md`, `docs/CORRECTNESS.md` and `docs/BENCHMARKS.md`.

Development used Claude Code (Anthropic) as a coding assistant under the owner's direction. The owner made the design decisions recorded in `docs/DECISIONS.md` and reviewed the results.
