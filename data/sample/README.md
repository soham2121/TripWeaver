# Sample data

`goa-osm-extract.json` is a filtered extract of OpenStreetMap data for Goa, India. It contains named points of interest, settlements and the Goa state boundary, from Geofabrik `western-zone-261122.osm.pbf` (OSM timestamp 2026-11-22T21:20:48Z).

`konkan-osm-extract.json` is the Mumbai–Goa road-trip corridor from the same extract: the bbox lat 15.60–19.10, lon 72.75–74.10 minus the Goa boundary. Same licence.
